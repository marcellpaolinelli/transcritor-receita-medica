# Transcritor de Receita Médica

Página web que transcreve receitas médicas nos dois sentidos: do código de posologia (como `1-0-1`) para texto legível ao paciente, e do texto pronto de volta para o código.

## Link público

Quando o GitHub Pages estiver no ar, o site fica em:

https://marcellpaolinelli.github.io/transcritor-receita-medica/

Não precisa de login. Qualquer pessoa com o link pode usar.

## Privacidade

O transcritor roda 100% no navegador, sem backend. A receita digitada não sai do seu computador: nada é enviado a um servidor, e o site não coleta dados de pacientes. Dicionários personalizados, se você editar, ficam salvos só no navegador em que foram alterados.

## Como usar

Abra o link, cole a lista de medicamentos na coluna de entrada e veja o resultado à direita. Há exemplos prontos e um painel de conferência para revisar o que foi interpretado.
